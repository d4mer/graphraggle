# GraphRAG Implementation

This repository contains the working files for the local GraphRAG deployment.

## Contents

1. `docs/`: operator documentation, quickstart, troubleshooting, and reference material
2. `scripts/install_rag_stack.sh`: installer/bootstrap script for the Mac mini stack
3. `CHANGELOG.md`: implementation history and validated fixes
4. `TODO.md`: follow-up hardening and feature work

## Source Of Truth

This folder is intended to be the tracked home for files related to this GraphRAG implementation.

The Desktop docs entry is intended to point here via symlink rather than maintain a duplicate copy.
